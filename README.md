## 💻 O que são Sistemas Operacionais?

Um **Sistema Operacional (SO)** é o software responsável por **gerenciar os recursos de um computador** e permitir que o usuário utilize o hardware e os programas.

Ele gerencia recursos como:

- 🧠 Memória RAM
- ⚙️ Processador (CPU)
- 💾 Armazenamento
- 🔌 Dispositivos de entrada e saída
- 📂 Arquivos e pastas
- 🖥️ Aplicações

### 📌 Exemplos

- 🪟 **Windows**
- 🐧 **Linux**
- 🍎 **macOS**
- 📱 **Android**
- 🍏 **iOS**

> **Resumindo:** o Sistema Operacional funciona como uma ponte entre o **usuário, os programas e o hardware** do computador.
