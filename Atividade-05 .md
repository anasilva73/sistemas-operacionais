🟦 PlayStation 4 — 2013

O caso do PlayStation 4 é um dos mais claros.

🎮 PlayStation 4

O Orbis OS foi desenvolvido utilizando uma versão modificada do FreeBSD. Portanto, existe uma relação direta entre a família BSD e o sistema utilizado pelo PS4.

O Xbox One utiliza uma arquitetura de sistema operacional desenvolvida pela Microsoft com forte relação com tecnologias do Windows. O sistema foi projetado especificamente para o console, mas compartilha tecnologias e componentes com a família Windows.

🟥 Nintendo Switch — 2017

O caso do Nintendo Switch é diferente. A Nintendo utiliza um sistema operacional proprietário chamado Horizon, desenvolvido especificamente para o console.

A evolução pode ser representada assim:

Nintendo GameCube
        │
        ▼
       Wii
        │
        ▼
      Wii U
        │
        ▼
Nintendo Switch
        │
        ▼
   Horizon OS

Aqui é importante destacar que não é correto dizer que o Horizon OS é simplesmente uma versão do sistema operacional do Wii U.

A relação está principalmente na evolução das tecnologias, arquitetura e experiência de desenvolvimento da Nintendo.

🟨 Wii — 2006

O Wii possui uma relação bastante interessante com o GameCube:

Nintendo GameCube
        │
        │ evolução da arquitetura
        │ e tecnologias
        ▼
       Wii
        │
        ▼
   Wii System Software

O Wii possui uma arquitetura muito próxima à do GameCube, utilizando uma evolução de seu hardware e de várias tecnologias de software.

Por isso, podemos considerar o Wii um exemplo de evolução de uma plataforma anterior, embora não seja simplesmente um "Wii OS baseado no GameCube OS".

📚 Resumo para colocar na atividade
Ano	Console	Sistema	Principal relação
2006	Nintendo Wii	Wii System Software	Evolução da arquitetura do GameCube
2013	PlayStation 4	Orbis OS	Baseado no FreeBSD
2013	Xbox One	Xbox OS	Tecnologias e arquitetura relacionadas ao Windows
2017	Nintendo Switch	Horizon	Sistema proprietário, resultado da evolução das plataformas Nintendo

Em resumo: o PS4 é o exemplo mais direto de reutilização de uma base de sistema operacional, pois o Orbis OS utiliza o FreeBSD como base. O Xbox One segue uma linha de evolução tecnológica ligada ao Windows, enquanto Wii e Switch representam principalmente a evolução interna das plataformas da Nintendo.
